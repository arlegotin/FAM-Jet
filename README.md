# FAM-Jet

Research specification for query-conditioned exponential-moment memory: compress a stream once, then answer different temporal questions from the retained state.

The primary decision is whether exact first temporal moments improve retrieval quality relative to tuned alternatives under measured state and system costs. A positive outcome would support a scoped empirical, numerical, or systems contribution. The recurrence alone is established repeated-pole memory.

Start with the [technical specification](docs/superpowers/specs/2026-10-16-famjet-design.md) and the [25-task implementation plan](docs/superpowers/plans/2026-10-16-famjet.md). The plan defines interfaces, behavioral tests, commands, acceptance gates, and commit boundaries for WP00–WP10; all execution checkboxes remain unchecked.

The [supplied-evidence record](docs/research/2026-10-13-source-record.md) distinguishes the brief's prior research from locally executed evidence. The [local discovery snapshot](docs/research/2026-10-16-local-environment.md) records the actual 36 GiB M3 Max and current capacity conditions. See [progress](PROGRESS.md), [decisions](DECISIONS.md), and the [planning audit](AUDIT.md) to resume work.

This repository currently contains planning documents. Project commands, dependencies, datasets, implementations, and trained results are future deliverables. The source brief's research cutoff is 13 October 2026; these documents were prepared on 16 October 2026.

The first implementation task is the local environment/compatibility gate. It must select a tested Python/PyTorch pair and discover a safe resource envelope before experimental execution. The full protected analysis code is tested before the pilot and preregistration; optional interpolation, probes, and language enter only through their recorded evidence gates. Work stays on the current branch as requested.
