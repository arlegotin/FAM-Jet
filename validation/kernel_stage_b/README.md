# Task 18 Stage B external adapter

This adapter is the proposed fixed-reader, descriptive actual-state panel. The only executable scopes are an empty native `binding` qualification and the complete 96-history, eight-query `panel`. The binding branch imports and records a worker baseline without constructing a model, encoding a history, reading, factoring, or scoring. The panel branch uses the six archived static exports, the unchanged Stage A guarded reader and supervisor, and central numeric-v2 scoring. It retains all original histories and all 24 Stage A source-fidelity failures; selection is restricted to complete finite configurations.

`prospective-plan.json` pins the original manifest/config/producer and archived A records. Its `approval`, `execution`, and `release` are `null`, so it is deliberately refused. `python -m validation.kernel_stage_b --help` displays the interface. A later root-owned release must provide manual failure dispositions, source compatibility, a fresh admission and deadline, an exact runtime/argv/output allocation, and a payload-bound release. A full panel release additionally requires an accepted zero-science binding report. No source commit or source test supplies that authority.

The adapter rejects feasibility subsets and single-query modes. It never executes the archived panel producer script or historical training/calibration paths. Every released invocation is bounded by the original allocation clock, unchanged native monitor, guarded reader worker, exact source manifest, and output cap. Infrastructure errors retain raw work and stop selection; numerical quarantine is scored through the unchanged central fallback policy.
