# Public release scope

FAM-Jet v0.1.0 publishes the implementation and the completed CPU64 fixed-writer numeric study. The public claim is a controlled empirical result with no demonstrated overall Jet advantage. Source inspection, component smoke checks, protected synthetic panels, finite-period sensor results and future language work remain distinct.

## Included in Git

- Original source, tests, executable configurations and pinned dependency locks.
- Canonical human/machine reports, three SVG figures, chart data and report receipts.
- Original execution-source archive, raw custody indices, protected release/inference records, actual report recovery and portable replay proofs.
- Scientific/adaptation specifications, final audit, failed-run records and dated amendments. Their historical pending labels refer to their own stage; the current README and final audit state the completed scope.
- License texts, attribution, citation metadata and the archived prepublication README.

## Included as a release asset

The unchanged `famjet-run06-evidence.tar.gz` contains the complete original run06, preparation inventory and source needed for report-only replay. SHA-256: `b6de6ba91c234a30bf885f5695b26244358749597bd9f043621f1a44bbd624ae`; 285,608,419 bytes. The release provides license/notice material alongside it. The copied run's scientific results were already released; this is not an inspection of unfinished private comparisons.

Git alone does not contain that 2-GB expanded raw evidence tree. [REPRODUCE.md](../REPRODUCE.md) gives download, verification and replay commands. The full source UCI archive and derived source arrays are obtained/prepared separately for a new scientific execution.

## Preserved metadata

Original records contain the owner's absolute local paths, timestamps, process/resource observations and source revisions. Those nonsecret provenance fields remain unchanged because the sealed hashes bind them. In the run06 bundle the local home paths appear in preparation witness fields and the real-release manifest path; the loader rebases copied paths. Public reports and Git history retain historical metadata too. These fields do not expose a credential or supply an external memory to a bounded-state method.

The full private scratch-workspace tar, environments, caches, unrelated jobs and excluded unfinished run04 private outcomes are not release assets. Git history is preserved; no claim is made that publishing a final tree deletes earlier versions.

## Publication cleanup

Broken absolute temporary symlinks in historical task18 evidence are removed from the current tree. They contained no available scientific payload and are outside every pinned executable/source archive/canonical-result path. The [removal inventory](publication/removed-temporary-links.json) records their repository paths and original Git blob identities; old Git revisions retain the exact link targets. Regular evidence files and sealed byte identities remain intact.

Publication checks and their limits are recorded in [the release audit](publication/readiness.md). A credential-pattern scan is evidence about its scanned material and patterns, not a guarantee about every possible secret or arbitrary binary file.
