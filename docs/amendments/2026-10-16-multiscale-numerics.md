## Common learned-map parameter gradients

Kernel states, outputs and direct input key/value/gate gradients retain elementwise `rtol=1e-5,atol=1e-6` in FP32; CPU64 stream/terminal checks retain `1e-12,1e-12`. Full common MLP parameter-gradient tensors additionally use the scale-aware acceptance criterion `||g32-g64||_F <= 1e-6 + 1e-5*||g64||_F`, with mandatory original pointwise error ratios, worst cells, loss/prediction scale and gradient norms reported. This criterion applies consistently to the common reader/writer/query maps across future families, not specifically to log-timescale memory. Direct coefficient-input gradients do not inherit this norm criterion.

## Failed FP32 state frontier, ordinary tolerance unchanged

The exact fixture n4,m2,epsilon1e-4,tau0=16,2048 events fails the **original state** criterion on both CPU and native MPS. Maximum error2.0244773e-4, maximum tolerance ratio4.63436,4/16 coordinates failing. CPU64 at the same configuration passes1e-12 (maximum ratio .06267). The regression reports `status=failed_original_tolerance,accuracy_accepted=false`; passing its diagnostic assertion verifies the failure record, not numerical acceptance. No skip/xfail or tolerance widening hides it.

The fixed2048-event fixture's prefixes isolate length effects. Stream FP32 tolerance ratios at N256/512/2048 are .27631/1.19466/4.63436; terminal FP32 ratios are .02529/.05789/.44057 (CPU and MPS identical in this probe). Repeated CPU64 arithmetic with quantized E32 promoted to64 gives ratios .11225/.19028/3.34958, whereas true E64 arithmetic gives errors below2e-13. A bounded, algebraically equivalent P+(E-I)P attempt reduced the N2048 ratio to3.23395 but still failed; it is preserved only as a diagnostic script and was **not adopted**. No persistent compensation or extra state was introduced.

Validated bounded FP32 rows include n2,m2,epsilon.01,tau0=3,N256 and n2,m4,epsilon.01,tau0=16,N2048; the latter's worst tolerance ratio is .27216 CPU/.26686 MPS. The explicit CPU smoke uses the latter allocation at N128, with eight coefficients matching the J4 jet payload. These fixtures do not establish acceptance for all intermediate or longer sequences or all orders/scales.
