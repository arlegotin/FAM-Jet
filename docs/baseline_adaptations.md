## Translated-Legendre memory — Task 13, 16 October 2026

`famjet/memory/hippo.py` independently implements the finite Leg-T equations in the binding specification §8. It does not vendor third-party source. The source reconciliation is R07, Goffinet, Hanks and Carlson, [HiPPO Zoo v2](https://arxiv.org/html/2602.21340v2#A4.SS3), cutoff 13 October 2026. The [Leg-T generator and reconstruction](https://github.com/jackgoffinet/hippo-zoo/blob/04e38b3cf246f4c50cb6c6a7e10597e2e37eebc7/src/mpm/polynomials.py#L75) have blob `efaca78a15cba574ef6017e6a195127b0cf00834`. At order2, `A=[[-1,sqrt(3)],[-sqrt(3),-3]]`, `b=[1,sqrt(3)]`. With age coordinate `s=0` at the present, the reconstruction basis is `sqrt(2i+1)(-1)^i P_i(2s-1)`. This is translated Legendre, not the separate scaled-Legendre system. Finite coefficient state does not imply exact sharp-window reconstruction or positive coefficients.

The pinned [multiscale script](https://github.com/jackgoffinet/hippo-zoo/blob/04e38b3cf246f4c50cb6c6a7e10597e2e37eebc7/scripts/multiscale_hippo.py) has blob `38f3efb7f5a3f2538cc4ce284b931770086e655e`; its sampled-signal convention uses the augmented-matrix ZOH input. No source is copied here; attribution identifies the equations and adaptations. Any future copied substantial source must retain the MIT notice.

The actual Task13 comparator receives event mass: `P_new=expm(A*Delta/tau)P_old+(b/tau)X`. Its fixed writer uses the identical raw nonnegative key/gate and signed numeric value augmented with1. Each bank has its own positive static tau and integer order; their coefficients are concatenated with no padded/unused states. Scalar order/tau construction is shorthand for a one-bank allocation. A separately named `zoh_transition` computes the sampled constant-signal interval input by augmented exponential. At zero gap, an event adds its full impulse while ZOH adds zero. Independent quadrature and constant stationary reconstruction controls verify both conventions; they must not be scored against each other's target.

State coefficients use physical inverse-time units. Generic contracted readers see every query-key-contracted coefficient; generic full readers see all key/value coefficients. Both receive `t_ref*P` and identical public query key/task/dimensionless age endpoints. Neither divides signed coefficients by a positive-mass normalizer. Numerical support means finite features in a valid nonempty snapshot, including finite zero coefficients; it does not certify factual key/window support. Nonfinite features retain failure evidence. Task17 still owns uniform failure/fallback/scoring and calibrated abstention.

`SnapshotMemory` shares only snapshot identity, exact host-time handling, stream ownership and public query scaffolding. Existing jet/bank diagonal propagation remains its specialized subclass. Every polynomial stream step is a native tensor matrix multiply. Terminal encoding uses exact chunked impulse sums with full value/key/gate gradients; causal learned writers remain a separate optional arm. Timescales are fixed configuration values, not learned parameters.

CPU NumPy/SciPy FP64 constructs generators, injection vectors and propagators. Only declared gap matrices persist as registered buffers, in the state precision; native CPU/MPS FP32 propagates the state. This explicit host computation is not framework MPS fallback. Arbitrary gaps are prepared afresh, transferred explicitly, and never stored in a persistent memo table. `prepare_transition` returns local host preparation time and work; `call_preparation_cost` inventories all fresh encode/read forward gaps, including padding and the second advance for a generic-full read. Training wall time includes host preparation; logged work is explicitly forward-only because checkpoint recomputation can repeat it during backward. `matrix_cubic_work` is a dimension-based work proxy, not an exact FLOP count. Matrix construction and complete-model construction timing are separately reported. No throughput advantage is claimed.

For orders `n_a`, state payload bytes are `B*sum(n_a)*K*(V+1)*itemsize`; normal snapshot metadata is unchanged. Cache bytes are `len(declared_gaps)*sum(n_a**2)*itemsize`, injection bytes `sum(n_a)*itemsize`. Static buffers count separately and in end-to-end totals. Defaults declare gaps0/1/2/4/16; setting an empty alphabet with cache_limit_bytes0 disables persistent transition storage. Cache demand is checked before construction. Allocation/schema bounds are implementation safety bounds, not a scientific frontier selection: at most64 banks/gaps, order256 and total1024 coefficients. Smoke training retains the existing small envelope and allows at most8 coefficients, matching four jet anchors' payload. Non-smoke calibration/tuning remains Task18/20.

## Task14 finite log-rate construction

`famjet/memory/multiscale.py` independently implements the **log-g script** at the R07 pin above. A new read of the exact script verified Git blob `38f3efb7f5a3f2538cc4ce284b931770086e655e`; no source code is vendored. The MIT source attribution remains above. The script's finite G is `sqrt(epsilon)*exp(L*Jx/2)`; it is not the generic helper's rate-coordinate system or exact projected infinite multiplication. Construction uses the equivalent shifted exponential `exp((L/2)*(Jx-I))`. G shares Jx's eigenbasis, so one symmetric Jx eigensolve yields its eigenvectors U and positive `gamma=exp((eig(Jx)-1)*L/2)` without losing small eigenvalues to cancellation in a dense G eigensolve. Column signs are canonicalized for deterministic Q serialization.

Analytic beta uses exponentially scaled modified Bessel `ive(r+1/2,L/2)*sqrt((2r+1)*pi)`, algebraically equal to the source's spherical-Bessel expression without overflowing intermediate exp/Bessel factors or computing1/epsilon. Independent converged256/512-node quadrature verifies eps .999999 through1e-300 on bounded orders. B=b beta^T; store Q=P U, inject B U/tau0, propagate each temporal column with exp(A gamma_j Delta/tau0), query Q(U^T psi). The du-orthonormal scale basis has no alternating sign. For m1, G00=sqrt(epsilon), beta0=(1-epsilon)/sqrt(log(1/epsilon)); correct single-scale control multiplies the corresponding polynomial memory by beta0/gamma0. Finite signed injection is never a positive mass denominator.

All n*m coefficients remain accessible to both generic readers. `scale_features` returns dimensionless temporal coefficients at an explicitly represented rate in [epsilon,1]; it does not silently clip or promise a sharp-window reconstruction. Physical inverse-time coefficients become t_ref*Q for complete-predictor time-unit consistency. Event impulse adaptation and sampled-signal augmented-exponential ZOH are separate named APIs with independent controls.

CPU FP64 preparation, finite-system expm/eigensolve/Bessel work and native matrix transfers are included in complete model construction timing. Declared-gap matrices, signed injection and U are registered static buffers and byte-counted; only declared bounded gaps persist. Uncached gap preparation is CPU64, explicitly timed, with operation counts, and contributes to inclusive training wall time and measured process/allocator peaks. Temporary construction arrays and SciPy/BLAS workspace are not persistent state; exact internal workspace is not claimed, and cold resource calibration remains Task20. No hidden arbitrary-gap cache or framework fallback exists. The snapshot budget counts every coefficient and metadata field; no dummy padding achieves equal bytes. Explicit n2*m4=8 matches the J4 jet payload, with different static/basis/cache costs reported separately.

The [configuration amendment](amendments/2026-10-16-multiscale-config.md) and [numerical amendment](amendments/2026-10-16-multiscale-numerics.md) are binding scope records. **The FP32 n4/m2/epsilon1e-4/tau0=16 long-stream frontier is not accepted** (N512/2048 fixed-prefix failures); CPU64 at the same2048 fixture passes. Task18 must require fresh matched numerical evidence or an explicit precision/frontier choice before scientific use. The accepted bounded FP32 fixtures and component tests do not prove convergence, cold-MPS capacity, universal stability, speed, gain or broad competitiveness.

The [NVIDIA Source Code License-NC](https://github.com/NVlabs/GatedDeltaNet-2/blob/de8476de0fecae08fc16f0bf3154900244c61c73/LICENSE), blob `d50677fec39f78e04515c615d30ad16741f8a29c`, restricts source/derivatives to noncommercial research/evaluation and imposes notice obligations. No source, Triton/FLA kernel or pretrained weight is vendored. Independent equation implementation is not legal clearance.

The native event control and deferred task adaptation are explicitly distinct in the [configuration/method amendment](amendments/2026-10-17-native-delta-config.md). For normalized signed k and q, with denominator `sqrt(sum(x²)+1e-6)`, `Sbar=alpha*S`, `Snext=Sbar+k*(w*v-Sbarᵀ(b*k))ᵀ`; output reads Snext with q/sqrt(K). Native q/k/v projections have no bias, followed by chronological size4 depthwise convolutions and SiLU. Caches store projected inputs, never raw histories. Decay uses `-exp(A_log)*softplus(F2(F1(x))+dt_bias)` without intermediate activation or an extra gap factor. Output uses learned V-wide RMS scale shared across per-head applications, epsilon1e-5, a two-layer D→V→HV gate (second affine has bias), SiLU and HV→D projection. KDA ties b/w scalar per head; GDN additionally ties decay. Doubled erase applies only to untied GDN2 b, leaving w in (0,1).

A_log/dt_bias have no weight decay. Because the FLA dependency revision was unpinned, the native convolution explicitly uses uniform[-1/sqrt(L),1/sqrt(L)] and RMS scale1; these are declared local initializers, not a claim of matching dependency RNG/defaults. Trainable E/R adapters use the same Xavier convention.

`raw_paper` and `pinned_guarded` are separately named policies. The latter includes the pinned repository's default erase guard and STE convention using ordinary tensors. Active/inactive/zero-key/strong-decay and exact quantized-forward controls accompany an independent CPU64 matrix unroll. No hidden CUDA, fused-kernel equivalence or automatic CPU fallback is asserted. CPU/MPS tests and tiny excluded-history learning controls establish bounded implementation behavior; scientific convergence, comparative quality and cold-MPS resource calibration remain open. Training and snapshot bytes include all native work/state, while native event-control reports explicitly exclude the unused task-input adapters from its optimizer and parameter count.
