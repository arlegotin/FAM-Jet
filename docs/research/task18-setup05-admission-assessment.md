The decisive distinction is between the Mach API counter and vm_stat's printed counter. The installed `/Library/Developer/CommandLineTools/SDKs/MacOSX.sdk/usr/include/mach/vm_statistics.h:158–163` says speculative pages already belong to API free_count; they hold speculative disk reads not yet used. Adding API speculative_count to API free_count would double-count. Apple's official vm_stat source, however, prints “Pages free” as free_count minus speculative_count, then prints speculative_count separately (snapshot lines126/129; periodic display lines196/198). Therefore summing the two printed counters in the retained observation restores API free_count without duplication. The installed vm_stat manpage names both lists but does not explain this subtraction; its wording alone is insufficient. This is source-based semantic support, not a claim to have reproduced the installed executable's build. [Apple vm_stat source](https://github.com/apple-oss-distributions/system_cmds/blob/main/vm_stat/vm_stat.c#L121-L148), [Apple kernel header](https://github.com/apple-oss-distributions/xnu/blob/main/osfmk/mach/vm_statistics.h).
