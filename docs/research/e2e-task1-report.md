Synthetic protected generation also verifies exact population and requested episode. `iter_beijing` requires current-v2 seal, official archive SHA/size, training normalization, chronological block inventory, NPZ byte hash, array inventory, and replayed raw/normalized oracle labels, support and counts. Test access requires a grant; `beijing_unit_test` is restricted to a separate temporary root and unit-test grant. `invert_normalized_prediction` adds training mean for mean/latest but never contrast.

`build_model` creates native Jet4/Bank8 at `geomspace(alpha_min,alpha_max)/t_ref`, independent of K/V. `RidgeMemoryModel` exposes `init_state`, `encode`, `advance_copy`, `read`, `persistent_nbytes`, `parameter_nbytes`, frozen-copy `target_statistics`, and writer-only snapshot hash. Query reads use only snapshot and queries. Each coordinate has 33 ordered features `[1,u8,u8/(m+eps),log1p(m8),1[m8>floor]]`; the shared scalar coefficient vector has 264 or 528 entries from q8/q16 outer products. Negative/nonfinite masses fail; unsupported and numerical-failure flags reach the existing `ReadResult`. Reader updates preserve writer snapshot identity.

`fit_training_metadata(factory)` derives frozen target statistics and median positive gap without retaining raw histories. `make_fit_manifest(model, metadata)` binds source, lock, writer, shape, config, task priors, regime weights and ordered row hashes. `fit_reader(model, episode_factory, fit_manifest, chunk_rows=1024)` requires a replayable callable, rejects development/changed/refit rows, verifies training-only eligibility and statistics, then streams pooled feature/query scalers and weighted sufficient statistics. Weights equalize regime, history, task, eligible query and coordinate, then divide by training task scale squared and normalize. The CPU64 normal solve updates the model only after finite objective and scaled residual at most `1e-7`. Zero-SD scaler columns use scale one. `FitArtifact` records coefficients, rates, scalers, objective, residual, solver, source/data/config/statistics commitments, elapsed time, and logical buffer ledger; RSS is explicitly unmeasured. `save_model`/`load_model` use JSON plus NPZ (`allow_pickle=False`) with exact array shapes, SHA-256 inventory and source binding.

`qualify_models(out)` is the later callable eight-case source gate: two shapes × two families × q8/q16, fixed ridge `1e-10`, alpha maximum 1, `t_ref=1`, original four-history two-age fit and 32 fresh histories with recorded seeds 2026102403/04. It writes every task/key normalized MSE and independent augmented-SVD objective/prediction and direct two-age reconstruction diagnostics. Gate thresholds are MSE `1e-4`, reference prediction `1e-7`, objective difference `1e-8`, reconstruction `1e-12`. **It was not called in E1.** This proves only implementation readiness, not qualification, generalization or a protected result.
