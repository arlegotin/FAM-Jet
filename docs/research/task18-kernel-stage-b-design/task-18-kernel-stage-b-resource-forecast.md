## Observed baseline and limits of inference

The archived A06 [driver](../../../docs/research/task18-kernel-stage-a06-evidence/stage-a/stage-a.json), [monitor](../../../docs/research/task18-kernel-stage-a06-evidence/stage-a/monitor.json) and [external receipt](../../../docs/research/task18-kernel-stage-a06-evidence/setup/prelaunch/stage-a-external.json) record 744 one-query reads, 750.063 s in guarded dispatch (1.008 s/read average), 757.126 s driver work, 902.697 s monitor elapsed, and 902.791 s external elapsed. Executed-slot elapsed has median 1.013 s, p95 about 1.067 s and maximum 1.166 s. The monitor entered finalization at 758.563 s: its remaining 144.134 s is real accounting/commit time, not available scientific work. Its evidence journal is 46.36 MB; output before the monitor report is 78.84 MB. Sampled incremental worker peak is 292.37 MB and sampled absolute process-tree peak 493.85 MB. Neither sample bounds continuous peak RSS. The A06 384 MiB incremental and 192 MiB output ceilings were allocations, not B measurements.

The 744 archived stdout streams are 6.57–8.64 KB each, median 7.55 KB. Their final one-query records contain 0/1/2 windows in 48/552/144 reads, respectively; final records range 739–2,525 B. Much of each stream is emitted counter lines. The Stage B worker will still start once per request, but eight queries cause per-query advance, up to 16 windows, more clone/counter lines and larger numeric/trace arrays. Therefore **576 × 1.008 ≈ 581 s is only a one-query transport-startup baseline**, neither a measured eight-query dispatch duration nor a panel forecast. The source permits 0–16 executed windows per eight-query request; realized counts and bytes depend on tasks and short-circuit paths. Do not multiply the A one-query final record by eight as a bound.

The [A fixture descriptors](../../../validation/kernel_stage_a/fixture-descriptors.json) contain 63 events per family. A06 timed 62 *bulk* encode calls across 126 fixture events at 0.03785 s total, approximately 0.30 ms/event if divided mechanically. Stage B uses an eventwise encode plus payload inspection after every event, so this quotient is **not a transferable per-event estimate**. The fixed EXPOSED manifest has 32 histories at each length 128/512/2048: 86,016 event writes per family, 172,032 total. Stored logical state stays 9,345 B, but episode tensors, repeated temporary state, serialization and supervision have separate RSS costs. A06 provides no defensible eventwise timing or eight-query peak-memory bound.
