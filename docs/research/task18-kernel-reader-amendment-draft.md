## Numerical eligibility and failure-complete scoring

An eligible window requires finite inputs/results, nonnegative canonical normalization channels, nonquarantined state, reconstructed mass `Chat>1e-8`, and `Chat>64*2^-53*sum_r(abs(c_r)*N_r)`. Both windows must pass for contrast. This cancellation guard is a prospective arithmetic policy, not a guarantee of small state error. No mass clipping, ratio clipping, positivity repair, epsilon search or history-assisted rescue is allowed.

Numerical eligibility is recorded separately from factual support. Reconstructed mass can be negative, cancel, or be positive for an actually empty window; it is never labeled an observed count, probability or factual interval-support result. Factual support estimation/calibration is unavailable in this proposal. Empty/single-impulse cases must expose leakage, not manufacture support. Constant vectors retain the declared epsilon shrinkage; mass rescaling changes effective epsilon and can change floor eligibility. Neither behavior may be concealed as exact invariance.

A failed query uses the existing frozen training-only unconditional task mean and retains its full loss, failure category and diagnostics. Nonfinite state invokes the existing quarantine behavior for subsequent queries. No dropped, silently rerun or selectively excluded primary query is permitted. Invalid/unsupported deterministic fixtures keep explicit status and use the existing target-validity convention; they do not acquire fabricated numeric oracle labels.
