## Fixed notation and construction metadata

Reference conversion uses exact integer-ratio/binary64-bit decoding, never shortened decimal strings. Nonfinite injection is the sole exception and is explicitly typed as a sentinel.

Lists specify complete observed histories. Sort by timestamp ascending, then written table/list position for equal timestamps; assign consecutive event IDs in that order. All eight coordinates are observed. Append exactly one **no-write** time-zero marker to every nonempty history, after any time-zero observed event; its value is O, key0, observation mask false for every coordinate, and its ID follows the writes. Default public query is key0, `T=0`, numeric mean, age interval `[0,4)`. `M[a,b)` changes its interval; `C[a,b)` requests recent `[a,b)` minus older `[b,2b-a)`. Semantic validity below means whether the exact observed-event target exists, **not** predicted support or numerical eligibility. No numeric target is supplied here.

## Independent reference and decision gates

Proposed mechanism is Python's standard-library `decimal` with independent scalar code, round-half-even, contexts80 and160 significant decimal digits, `Emin=-999999999`, `Emax=999999999`, and traps for invalid operation/division by zero/overflow. Independently solve the canonical scaled8-by-8 positive-ridge system using Gaussian elimination with largest-absolute-column partial pivoting and lowest-row-index ties. Zero/nonfinite pivot, unexpected sign/domain condition or Decimal exception is reference failure; do not adjust precision, coefficients or policy beyond the two declared passes.
