## Contracts and implementation

`famjet.eval.metrics.score_predictions(PredictionBatch, statistics, policy)` is the sole scientific scoring boundary. Public tensor contracts remain v1; external `metadata.scoring_v2` is closed and requires explicit output convention, boolean masks, tasks, effective prediction validity, quarantine and method/replicate/regime/manifest/statistics provenance. Factual support remains the versioned meaning of PredictionBatch.supported; raw numeric feature support is separate. The scorer validates training target semantics and statistics content hash. Unknown/ambiguous legacy scoring input rejects.

Every active query produces a row. Valid targets remain eligible after missing/failed/nonfinite/unusable output, invalid probabilities, quarantine or abstention. Numeric fallback is the exact task's frozen training mean, including change_sign; categorical/binary fallback retains the entire class prior. Effective prediction_valid governs usability, so binary absence/query-only answers survive unsupported raw memory features. Missing priors fail configuration even if a current prediction happens to be usable. Abstention affects acceptance/coverage only. The support head is explicitly unavailable as calibrated confidence; passing a supposed calibration document is rejected pending the actual separate-development calibration implementation.

Numeric losses are coordinate-mean squared errors divided by frozen task scale squared, with native MSE/MAE and constant-coordinate absolute errors. All-constant normalized loss is undefined. Primary scoring requires a positive scale, while smoke-checkpoint evaluation is labeled development diagnostics and may report undefined normalized loss without selecting a primary result. RMSE is square-root after aggregation, separately within each task's units. Binary/categorical CE uses stable logit arithmetic: binary logit−1000 for target1 has CE1000; a 32-class logit−1000 with31 zero logits has CE1000+log31. Actual zero-probability prior fallback retains explicit infinite-loss status/count and nullable JSON scalar; comparable effects reject infinity/undefined loss. Class distribution accuracy, Brier, confidence and ten fixed-width reliability/ECE bins are diagnostic. Query-weighted coverage/selective risk are labeled separately from primary aggregation.

`aggregate_scores`, `history_effects` and `history_effects_inventory` validate complete frozen inventories, duplicates, crossed H×S cells, tasks, regimes, target/provenance pairing and weights. Queries average within task/history; frozen task weights then equal histories within regimes and frozen regime weights apply. Pair orientation is baseline minus candidate. Sorted history/replicate order and history weights are in the companion artifact. Neither missing tasks nor infinite losses silently renormalize away.

`famjet.eval.runner.score_episode` integrates through existing `_prediction_records` and `evaluate_model`. It streams one event at a time with shared retained state, inspects every floating saved payload/cache field, and latches the first nonfinite state before further ingestion/read. Trigger evidence includes event offset, full triggering input values/features/auxiliary/observations, identity/time, fields and state/input/parameter hashes. Full later query inventory receives fallback. Finite unsupported reads affect only their queries. Schema/infrastructure errors propagate and fail the run. Host inspection cost is explicitly labeled synchronous evaluation overhead, not asynchronous kernel throughput. Existing terminal training is unchanged; old terminal raw reporting is explicitly historical/unscored.
