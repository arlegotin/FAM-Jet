## Scope and interfaces

`famjet_poc/protected.py` provides `freeze_study(inputs, out)`, `grant_for(freeze, phase, split, population, model_pair)`, `evaluate_cell(freeze, cell, grant, out)`, `seal_release(freeze, receipts, out)`, streaming `read_released_rows(release)`, and `infer_release(freeze, release, phase)`. The study freeze is write-once and binds selected checkpoint bytes, full executable tree, source/runtime, E2 attempt-2 acceptance and complete planned populations. Each grant verifies the accepted bundle bytes, scoped engine/runtime and original deadline before opening a protected population. The E2 numerical validation is cached for the current process and freeze, while all evidence bytes are checked before each grant. Cell scoring uses the exact E3 `evaluate_panel` with a 256-history local policy and the frozen eight-method inventory; release rejects missing cells, methods, histories, query IDs or byte-changed rows.

`famjet_poc/transfer.py` provides typed `PrefreezeTransferInputs`, `fit_transfer_modes(inputs, manifest, out)`, `load_bound_modes(ref, freeze)`, `evaluate_real_mode(mode, grant, out)`, `seal_real_release(...)`, and descriptive `block_sensitivity(...)`. Real fitting can only consume typed inputs before freeze; a `FrozenStudyRef` cannot create weights. The bounded replay cache serializes once-verified train/dev episodes and restores fresh content-checked copies for every fit. Two scientifically distinct modes, `synthetic_frozen` and `task_adapted`, bind both Jet and Bank checkpoints. The 56-block test is entered only after a mode-bound grant. Eight methods per mode include fixed controls and an independent Laguerre diagnostic. Native mean/latest values use scale and offset, while contrast uses scale alone; normalized scoring rows remain intact. The 28- and 56-day cluster resamples describe this finite test period.

`famjet_poc/pipeline.py` provides `run(out, resume=False)`, a hash-chained `StageLedger`, full-tree resource observation, fixed public stress inventory, secondary-task ledger, and timing admission. It reuses the accepted E1 and E2 gates only after byte/source/runtime verification. It performs a **fresh current-E3-source K16 probe before development**; the earlier K16 probe and 96-history/four-fit resource measurement remain historical inputs to the unchanged 2,400-second guard. It then performs K16 development and timing, separately probed K12 development, prefreeze real fitting, runtime model/inventory freeze, fixed stress diagnostics, all 36 protected cells, all 16 real mode/method runs, sealed releases, separate E2 confirmation and replication inference, then an E5 report call. No CLI Git mutation is performed. Root will make the protocol/source/config preregistration commit before actual execution; the CLI seals actual fitted weights and inventories at runtime before protected access. No unknown future checkpoint SHA is described as Git-committed before fitting.
