# Contributing

Small correctness, usability and documentation improvements are welcome. Report a reproducible issue with the source commit, environment, command and relevant configuration. Do not include credentials or unrelated local data.

Use [REPRODUCE.md](REPRODUCE.md) for installation and checks. Run inference tests separately from the broader suite. Full-archive integrations are opt-in. Numerical tolerances, persistent-byte accounting and causal query isolation are part of the contract; a fix should explain any changed behavior.

The published experiment is frozen. Preserve failed runs and old manifests; use a dated amendment and fresh protected data for a changed scientific claim. An improvement on one reader or task does not establish all-family or agent-memory superiority.

Contributions to original software use AGPL-3.0-only; original prose and result presentation use CC BY 4.0. Retain third-party terms and attribution as described in [LICENSING.md](LICENSING.md).
