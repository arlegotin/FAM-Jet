# Reproduce FAM-Jet

Run commands from the repository root. The published result is the CPU64 fixed-writer study in [the full report](reports/famjet-poc/final.md). A fresh execution of its registered seeds is a reproduction, not a new independent confirmation.

## Recorded environment

Use **native CPython 3.13.5 exactly**, macOS 14+ on ARM64, for the recorded lock and sealed report admission. The experiment used an M3 Max with 36 GiB unified memory. The main lock and reporting lock contain wheel hashes for that platform; they are not cross-platform locks. Generic package exploration on another platform does not establish reproduction of the reported experiment.

```sh
git clone https://github.com/arlegotin/FAM-Jet.git
cd FAM-Jet
python3.13 --version  # Python 3.13.5
python3.13 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r requirements.lock
.venv/bin/python -m pip install --no-deps --no-build-isolation -e .
python3.13 -m venv .report-venv
.report-venv/bin/python -m pip install --require-hashes -r docs/reporting-requirements.lock
```

Set `FAMJET_REPORT_PYTHON` to the reporting interpreter when rendering. No model API, pretrained language model or remote GPU is used by the core program.

## Check the implementation

The small numerical suite needs no dataset or full experiment archive:

```sh
.venv/bin/python -m pytest -q tests/test_algebra.py tests/test_time.py tests/test_gradients.py
```

Run the main suite and inference in separate processes:

```sh
FAMJET_REPORT_PYTHON=.report-venv/bin/python .venv/bin/python -m pytest -q --ignore=tests/test_poc_inference.py
.venv/bin/python -m pytest -q tests/test_poc_inference.py
```

The final delivery run recorded **1,774 passed, 58 skipped, two subtests passed**, followed by **22 inference passes**. A subsequent five-test check covered scratch-workspace retirement without changing production source. GPU/native-operation and optional archive integration skips are explicit; these counts do not claim every operation was validated on another host. Inference starts separately because its real 256-MiB process-lifetime RSS assertion must not inherit Torch loaded by other collected tests.

Two genuine full-archive admission cases are opt-in after obtaining the evidence:

```sh
FAMJET_RUN06_INTEGRATION=1 .venv/bin/python -m pytest -q tests/test_poc_report_recovery.py -k 'registered_admission or copied_admission'
```

The ordinary unit suite has no requirement for the old local run04/run06 archives. [Final verification receipts](docs/research/e2e-final-fix-evidence/) preserve failures, interruptions, the final passing run and exact commands.

## Replay the published report

The `v0.1.0` release provides the unchanged **285,608,419-byte** run06 evidence bundle. It expands to about 2.07 GB and includes the complete run, preparation records, original execution source, index and copy receipt. Leave room for the download, extracted files and report output. It contains no full raw UCI CSV/ZIP archive.

```sh
mkdir -p artifacts
curl --fail --location \
  https://github.com/arlegotin/FAM-Jet/releases/download/v0.1.0/famjet-run06-evidence.tar.gz \
  --output artifacts/famjet-run06-evidence.tar.gz
printf '%s  %s\n' \
  'b6de6ba91c234a30bf885f5695b26244358749597bd9f043621f1a44bbd624ae' \
  'artifacts/famjet-run06-evidence.tar.gz' | shasum -a 256 -c -
tar -xzf artifacts/famjet-run06-evidence.tar.gz -C artifacts
FAMJET_REPORT_PYTHON=.report-venv/bin/python .venv/bin/python scripts/report_run06_recovery_v2.py \
  --run artifacts/e2e-run06-original-archive/run \
  --archived-source artifacts/e2e-run06-original-archive/execution-source \
  --compatibility-id run06-report-safety-v2 \
  --out artifacts/public-replay/report/final.md
```

Use a fresh output destination. Do not extract over an existing evidence copy. The loader verifies the full original run/preparation/source inventories and the exact report-only transition before rendering. Absolute paths in historical records are preserved for their hashes and rebased during copied-run loading; they need not exist on your machine.

The seven canonical publication files were generated by the historical v1 reporter and independently reproduced byte-for-byte with original locations unavailable. Current v2 adds output safety and has separately recorded provenance. Its complete scientific JSON matches v1 after excluding only `report_recovery`; chart data, all three SVGs and renderer receipt are byte-identical. Markdown differs only in three reporter provenance hash lines. [V1 portable proof](docs/research/e2e-report-recovery-actual/index.json) · [V2 witnessed comparison](docs/research/e2e-final-audit/v2-report-replay/comparison.json)

The original normal CLI completed all scientific stages and exited **1 at report assembly** because a run-ID ordering check rejected an otherwise identical roster. The original failure remains recorded. Neither report recovery fits models, generates histories, grants protected access or changes old clocks.

## Prepare data and execute the study again

Obtain the official UCI outer archive, check its fixed hash, then prepare data. The inner `PRSA2017` ZIP alone is not the expected asset.

```sh
mkdir -p data/raw
curl --fail --location \
  'https://archive.ics.uci.edu/static/public/501/beijing%2Bmulti%2Bsite%2Bair%2Bquality%2Bdata.zip' \
  --output data/raw/beijing-uci501.zip
printf '%s  %s\n' \
  'b04da438b2f331ac0ffd45aebdfec0d20d2367feb5f6948c4b1f7ce1191e33c4' \
  'data/raw/beijing-uci501.zip' | shasum -a 256 -c -
.venv/bin/python -m famjet.prepare --config configs/data.yaml
.venv/bin/python -m famjet.prepare --config configs/beijing.yaml
FAMJET_REPORT_PYTHON=.report-venv/bin/python .venv/bin/python -m famjet_poc run --out artifacts/NEW-RUN
```

Choose a new run path. This is a multi-hour study, not the quick numerical check. The completed original run spent about 7.16 hours under its original eight-hour allocation; that is a recorded wall time, not a forecast for another machine. Discovery/admission checks select a correct local path and preserve failures rather than silently changing the population or budgets.

A fresh current-source run uses the ordinary `python -m famjet_poc report --run RUNROOT --out MARKDOWN` report command. Historical run06 requires the explicit v2 recovery above; it cannot be resumed under changed source. The CLI supports `--help`. For a separate two-step engineering smoke check, use `.venv/bin/python -m famjet.run --config configs/smoke.yaml`.

The UCI data remain CC BY 4.0. Credit Chen, S. (2017), *Beijing Multi-Site Air Quality*, DOI [10.24432/C5RK5G](https://doi.org/10.24432/C5RK5G), and retain the [transformation/attribution notes](THIRD_PARTY_NOTICES.md).

## Provenance and limits

Scientific executable and dependency hashes, raw prediction maps, failed runs, numerical limits, source licenses and method adaptations are retained. The [final audit](docs/research/e2e-final-audit/README.md) distinguishes source checks, actual execution and replay. [Publication scope](docs/PUBLICATION.md) lists what is distributed. Saved original paths and source revisions describe the experiment, not the current release checkout path.

Do not modify sealed results or rewrite old manifests to make an altered experiment appear identical. A changed scientific claim needs its own specification, selection and protected evaluation.
