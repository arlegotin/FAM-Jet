## Estimand, outcomes and uncertainty

For each history, average numeric query loss within task, then average mean and contrast equally. Normalize squared error with task/coordinate statistics fitted only on training. Average histories within each stratum, then the 12 strata equally. Positive effect means Bank loss minus Jet loss. The primary estimand conditions on the actual fitted models, training corpus/statistics and development selection; **retraining variation is excluded**.

Use the separately qualified `conditional_history_welch_v1` stratified Welch–Satterthwaite interval and two-sided p-value, exactly as implemented and calibrated. This is an approximate conditional-history interval, not universal exact coverage. A positive replicated conclusion requires a positive lower interval endpoint in both confirmation and replication. Report direction, interval, observed tails/failures, and applicability limitations even if evidence is null or unfavorable. Secondary comparisons are descriptive; the inferential secondary family is empty. No application-specific error tolerance or economic threshold is specified, so no unconditional practical-superiority or break-even claim is authorized.

Valid primary targets always receive a loss. Unsupported/nonfinite predictions use the frozen training-only task prior and retain failure flags; failed episodes are never silently dropped. Invalid targets remain in the full query inventory and count diagnostics, outside numeric loss according to the frozen target-valid policy. Missing paired histories/tasks, altered weights or incomplete releases block inference. Exact/gamma and A/A controls cannot manufacture independent observations.
